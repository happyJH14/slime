# 🟢 Slime Evolution RPG

단일 HTML 파일로 동작하는 브라우저 기반 탑다운 액션 RPG.  
Three.js 기반 렌더링 · ECS 구조 · 진화 시스템 · 스킬 드랍

---

## 조작법

| 키 | 동작 |
|---|---|
| `W A S D` / `↑ ↓ ← →` | 이동 |
| `H` | HP 포션 사용 |
| `1` ~ `5` | 스킬 사용 |

전투는 몬스터와 접촉하면 자동으로 진행된다.

---

## 스탯

| 스탯 | 설명 |
|---|---|
| **LVL** | 현재 레벨. 경험치를 쌓아 상승 |
| **HP** | 체력. 0이 되면 사망 |
| **MP** | 마나. 스킬 사용에 필요하며 초당 5씩 자동 회복 |
| **ATK** | 공격력. 몬스터 접촉 시 자동 공격 |
| **SPD** | 이동 속도 |

---

## 레벨업 & 스탯 배분

레벨업 시 **스탯 포인트 3개**를 획득한다.  
화면 중앙에 배분 창이 열리며, 원하는 스탯을 3번 선택해 닫는다.

| 선택 | 효과 |
|---|---|
| ❤️ HP | MAX HP +5 |
| ⚔️ ATK | 공격력 +3 |
| 💎 MANA | MAX MP +10 |

- 진화 연출 중에는 연출이 끝난 뒤 배분 창이 열린다
- 사망 시 배분 창은 자동으로 닫힌다

| 레벨 | 이름 | 보너스 |
|---|---|---|
| 1 | 🟢 Green Slime | 기본 |
| 10 | 🔵 Blue Slime | HP+80 / ATK+15 / SPD+10 |
| 20 | 🔴 Fire Slime | HP+200 / ATK+40 / SPD+20 |
| 30 | 🩵 Ice Slime | HP+400 / ATK+70 / SPD+30 |
| 50 | 🐲 Dragon Slime | HP+900 / ATK+160 / SPD+40 |

진화 시 스탯 배분 보너스와 아이템 보너스는 그대로 유지된다.

## 지역 (Region)

세계는 세로로 배치된 3개의 구역으로 나뉜다.

| 구역 | 이름 | 권장 레벨 |
|---|---|---|
| Region 1 | 🌿 Forest Meadow | Lv 1+ |
| Region 2 | 🌋 Lava Cave | Lv 12+ |
| Region 3 | 🏔️ Frozen Mountain | Lv 25+ |

각 구역에는 고유 몬스터와 보스가 존재하며,  
보스는 권장 레벨에 도달하면 자동 출현한다.

## 아이템

몬스터 처치 시 일정 확률로 드랍된다.

| 아이템 | 효과 | 드랍률 |
|---|---|---|
| 🧪 HP Potion | 인벤토리에 추가. `H`키로 사용 시 최대 HP 30% 회복 | 18% |
| 💛 ATK UP | 공격력 약 8% 즉시 증가 | 12% |
| 💗 MAX HP UP | 최대 HP 약 8% 증가 + 즉시 회복 | 보스 드랍 |
| 🟠 POWER UP | 공격력 약 15% 즉시 증가 | 보스 드랍 |

---

## 스킬 시스템

### 스킬 획득

- **일반 몬스터**: 처치 시 **1% 확률**로 스킬 드랍
- **보스**: 처치 시 **100%** 스킬 드랍
- 스킬 드랍은 육각형 빛나는 아이콘으로 표시되며 접촉하면 자동 획득
- 최대 **5개** 슬롯, 중복 획득 불가

### 스킬 목록

| 키 | 스킬 | 마나 소모 | 쿨타임 | 효과 |
|---|---|---|---|---|
| `1` | 🔥 FIREBALL | 20 | 4초 | 주변 200 범위 내 전체 적에게 ATK×1.5 피해 |
| `2` | 💚 HEAL BURST | 25 | 8초 | 최대 HP의 25% 회복 |
| `3` | ⚡ SWIFT RUN | 15 | 6초 | 3.5초간 이동속도 +80% |
| `4` | 💢 BERSERK | 30 | 10초 | 5초간 공격력 2배 |
| `5` | ❄️ ICE NOVA | 22 | 7초 | 주변 210 범위 적에게 ATK×0.7 피해 + 1.8초 빙결 |

스킬 슬롯은 화면 하단 중앙에 표시된다.  
마나 부족 또는 쿨타임 중에는 사용 불가.

## 전투 메커닉

- **자동 공격**: 몬스터와 접촉 시 0.55초 간격으로 자동 공격
- **크리티컬**: 12% 확률로 2.2배 피해 (★ 표시)
- **무적 시간**: 피격 후 0.75초 무적
- **빙결**: ICE NOVA 피격 몬스터는 1.8초간 이동·공격 불가 (파란색 표시)

## 기술 구조

```
Three.js (WebGL 렌더링)
 └── Orthographic Camera
 └── Sprite 기반 Entity

ECS (Entity Component System)
 └── Player, Monster, Item, SkillDrop

Systems
 ├── sysMovement  — 플레이어 이동 + 속도 버프 적용
 ├── sysRegion    — 구역 전환 감지
 ├── sysMonsterAI — 몬스터 추적 + 빙결 처리
 ├── sysCombat    — 전투 판정 + 드랍 처리
 ├── sysItems     — 아이템 픽업
 ├── sysSkillDrops — 스킬 드랍 픽업
 ├── sysSpawn     — 몬스터 스폰
 └── sysMana      — 마나 재생 + 버프 타이머
```
